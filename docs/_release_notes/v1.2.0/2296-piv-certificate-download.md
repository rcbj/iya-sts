---
title: "Download a new PIV certificate on the portal"
kind: added
issue: 2296
---
After a PIV certificate is issued on the portal's **Tokens and keys → PIV**
tab, a **Download cert.pem** button beside the certificate saves it under the
name the `ykman piv certificates import` command on the page uses. There is
no longer any need to copy it out of the box by hand.
