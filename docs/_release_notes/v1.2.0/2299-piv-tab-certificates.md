---
title: "The portal's PIV tab lists your PIV certificates"
kind: added
issue: 2299
---
The **Tokens and keys → PIV** tab on the user portal now lists every
certificate issued to you under a PIV profile, newest first. Each row shows
its slot, profile and key, subject, serial, expiry and state. The one just
issued is highlighted, as on the Certificates page. Each PEM box on the
enrolment form now has its file chooser beside it on the same row.
