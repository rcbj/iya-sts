# Search

The box in the header searches the guides of one version: the version of
the page you were reading, or the latest when you start from the landing
page. It matches the title, the headings and the text of each page, and
opens the page at the heading that matched.

The generated API reference under each version's `api/` is a separate
tree and is left out of the index.
